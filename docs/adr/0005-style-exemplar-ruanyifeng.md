# Style exemplar per language: a short, extensible list

The skill's primary mechanism for defining "good, plain writing" is a named style exemplar per language, rather than a written-out list of stylistic dos and don'ts. This borrows the same trick `wait-what` uses with ASD-STE100: name something the model already has a rich, coherent internal representation of from training, instead of re-deriving that representation from scratch as an explicit rule list.

The list currently has two entries — Richard Feynman for English, 阮一峰 (Ruan Yifeng) for Chinese — kept as a plain bullet list inside `SKILL.md` rather than a separate disclosed reference file, because every invocation needs to resolve exactly one entry from it and the list is short enough that keeping all of it inline costs almost nothing. Adding a new language is one bullet line, no restructuring. For a language not yet in the list, the skill falls back to a generic instruction (pick someone with that same reputation) rather than leaving the case undefined.

The bar for adding an entry: a real, safely-referenceable person — an established, uncontroversial reputation; a living person with their own brand built around writing style is a reason for caution — whose public reputation is specifically for plain, accessible writing, not literary or scholarly merit. 阮一峰 was chosen over 汪曾祺 and 万维钢 (considered for Chinese) and 李淼 (considered as a physics-specific match) on exactly this axis: his reputation ("接地气"/grounded, "通俗易懂"/easy to understand) is built entirely around accessibility, with no literary-elevation association to accidentally invoke, in the same tech-writing domain this skill's use cases live in. Richard Feynman is the same shape of choice for English — deceased, canonical, already a standing "explain it simply" reference independent of this skill.

A short layer of durable structural principles still backs this up as a fallback, for models whose training data gives them a shallower grasp of the named person's actual style than a surface-level caricature of it (a real, not yet tested, risk — see the eval fixture plan).
