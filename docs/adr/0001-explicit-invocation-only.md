# Explicit invocation, not auto-fire

The skill only runs when explicitly invoked (e.g. asked to translate or polish something into Chinese) — never automatically whenever the agent is about to output Chinese prose. Chosen because the user deliberately separates drafting an idea in English from the decision to translate it, and sometimes stays in English past the point an auto-firing skill would have triggered. Most "writing quality" skills default to matching their description automatically; this one deliberately doesn't, so the user keeps full control over when a translation pass happens. Invocation is a literal, explicit command — not natural-language phrase-matching. There are no "wake words" (e.g. saying "translate this to Chinese" in passing should not trigger it); the SKILL.md description is written narrowly enough to avoid acting as an autonomous trigger surface.
