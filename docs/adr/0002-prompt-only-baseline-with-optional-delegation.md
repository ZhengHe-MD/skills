# Prompt-only baseline, delegation is optional

The skill's core technique must work standalone as prompt engineering inside whichever agent is running it (Claude Code, Codex, Cursor, etc. via `npx skills add`), with zero external dependencies. This matters because the user has observed real gaps in Chinese-writing quality across agents — Claude/Codex weaker, Antigravity/Gemini stronger — and a skill that only works when a specific external CLI happens to be installed would break on many installs. Shelling out to a stronger external model (e.g. a `gemini` CLI) is allowed as an optional enhancement when available, never required. When it is available, the skill always asks before using it — shelling out to an external tool is a side effect with its own trust and permission implications, and should never happen silently.
