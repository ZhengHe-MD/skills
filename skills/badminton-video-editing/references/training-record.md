# Training record

Retain all substantial practice in source order. Runtime follows the session; there is no duration target or minimum clip length.

| Visible activity | Selection |
| --- | --- |
| Footwork, shadow rehearsal, warm-up, or sustained feeding | Keep the meaningful sequence. |
| Substantial practice with mistakes or a failed final shot | Keep, including the outcome. |
| Miss followed promptly by continued practice | Keep within the bout; a dead shuttle alone is not a break. |
| Attempt stops almost immediately, followed by a clear reset | Remove when it is clearly an aborted start. One or two exchanges can support that judgment, but are not a threshold. |
| Separate rest, conversation, collection, arranging shuttles, or coach reload | Remove, even if only a few seconds between groups of the same routine. |
| Coach demonstration while player watches | Remove. Inspect active player rehearsal separately and keep meaningful practice. |
| Side change or drill variation | Keep practice on each side; remove setup time. |
| Uncertain short sequence | Inspect more closely; prefer retaining it if its status remains uncertain. |

Classify visible activity before considering duration. A brief rally can be valuable; a long interval can be entirely discussion. Repeatedly cutting ordinary recovery destroys the movement record the player needs.

Before refining boundaries, check the full timeline map against the candidate list: every substantial practice interval must be retained or have a specific reason for exclusion. Check all requested routines and their meaningful side variations, not merely one occurrence of each routine. Later groups still belong in the record.
